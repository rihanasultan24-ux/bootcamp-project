## 🖌️ Adding the CSS (External File)

Right now, your CSS is embedded inside the `<style>` tag in your HTML. To make it cleaner, you can move it into a separate file called `style.css`.

### Step 1: Create `style.css`
Copy everything between `<style> ... </style>` into a new file named `style.css`.

### Step 2: Link CSS in HTML
Replace the `<style>` block in your HTML with:

html
<link rel="stylesheet" href="style.css">
```

### Step 3: Keep Fonts & Icons
Leave the Google Fonts and Font Awesome `<link>` tags in the `<head>` section, since they are external resources.
